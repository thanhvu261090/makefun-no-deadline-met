## The entry

> My calendar reminded me about the deadline the same way I remind myself to floss — right after it was already too late.

**Character count: 121** (limit: 200, single line).

The joke: the calendar reminder — the one tool supposed to save you from missing the deadline — shows up late, and the line blames it with the most relatable procrastinated chore there is: flossing. Everyone knows the "I'll floss tomorrow" loop, so the excuse lands as something a real person would actually say, while the twist is that the reminder itself was the thing that failed.
